Endpoints

  • GET /api/health — startup validation, archives, cache and index
  • GET /api/cache-stats — live cache and index counters
  • GET /api/missing-files — assets that were requested and not found
  • GET /list-files — every indexed path
  • POST /search — {"filter": "<regex>"}
  • POST /batch — {"files": […]}, 1–50 paths, base64 results
  • GET /<path> — a static file, then a GRF asset
  • WS /ws/<host>:<port> — proxied to rAthena, when enabled
